# cc-helper v1.1.0 — 三按钮权限审核模式

## 1. 概述

当前版本仅支持两按钮权限审核（Deny / Allow），无法表达 Claude Code CLI 中的 "Yes, allow all edits during this session (shift+tab)" 选项。本次更改增加三按钮模式：当 hook 数据中包含 `permission_suggestions` 时，UI 显示 **Deny / Always Allow / Allow** 三个按钮。

## 2. 行为规范

| 条件 | 按钮数量 | 按钮 |
|------|---------|------|
| `permission_suggestions` 非空 | 3 | Deny, Always Allow, Allow |
| `permission_suggestions` 为空/不存在 | 2 | Deny, Allow |
| AskUserQuestion 模式 | 不变 | Cancel / Submit |
| Skill 模式 | 不变 | Deny / Allow |

## 3. 数据流

### 3.1 Claude Code hook payload 结构（输入）

```
{
  "session_id": "...",
  "cwd": "...",
  "tool_name": "Bash",
  "tool_input": { "command": "npm test" },
  "permission_suggestions": [...]    ← 顶层字段，不在 tool_input 内
}
```

**关键修正**：`permission_suggestions` 位于 payload **顶层**，不是 `tool_input` 的子字段。此前代码错误地从 `payload["tool_input"]["permission_suggestions"]` 提取。

### 3.2 前端到后端（输出）

点击按钮调用 `invoke('resolve_permission', { key, allowed, always, answers })`：

| 按钮 | `allowed` | `always` |
|------|----------|---------|
| Allow | `true` | `false` |
| Always Allow | `true` | `true` |
| Deny | `false` | `false` |

后端 `Response` 映射：
- `always=true` → `Response::always_allow(suggestions)`，返回 `updatedPermissions` 包含权限规则
- `always=false` → `Response::allow()`

## 4. 各层修改明细

### 4.1 Rust 后端

**island.rs**
- `PendingRequest` 新增字段 `permission_suggestions: Vec<serde_json::Value>`
- 提取路径修正：`request.payload["permission_suggestions"]`（从顶层取，不再嵌套 `tool_input`）
- `resolve()` 使用 `pending.permission_suggestions` 替代 `pending.tool_input.get("permission_suggestions")`
- `IslandRequestPayload.permission_suggestions` 类型从 `Option<Vec>` 改为 `Vec`（用 `unwrap_or_default` 处理空值）

**dialog.rs**
- `PendingRequest` 新增字段 `permission_suggestions: Vec<serde_json::Value>`
- 同样的提取路径修正
- URL 新增 `suggestions` 参数：`/src/dialog.html?...&suggestions={}`
- `resolve()` 使用 `pending.permission_suggestions` 直接访问

### 4.2 TypeScript 前端

**dialog-main.ts**
- `permissionSuggestions` 从 URL params `suggestions` 提取（不再从 `toolInput.permission_suggestions` 取）

**global.d.ts**
- `__helperResolve` 签名增加 `always?: boolean`：`(allowed, always?, answers?)`

### 4.3 Vue 组件

**PermissionDialog.vue**
- props 新增 `permissionSuggestions?: Array<Record<string, any>>`
- 新增 `allowAlways()` 函数，调用 `__helperResolve(true, true)`
- 所有权限模式 footer 加条件按钮：`<button v-if="permissionSuggestions?.length" class="btn always-allow">Always Allow</button>`
- `__helperResolve` 调用统一传入 `always` 参数

**DynamicIsland.vue**
- `PendingReq` 接口新增 `permissionSuggestions?: Array<Record<string, any>>`
- `doAllow()` 增加 `always: boolean` 参数
- 新增 `allowAlways()` 函数，调用 `doAllow(true)`
- `submitOrNext()` 调用改为 `doAllow(false, {...answers})`
- 所有权限模式 footer 加条件按钮（同 PermissionDialog）
- `listen<PendingReq>` 回调中赋值 `pending.permissionSuggestions = p.permissionSuggestions`

### 4.4 CSS

**styles.css**
- `.btn.always-allow`：蓝底白字 (`#3b82f6`)，hover 变深 (`#2563eb`)
- Dark mode：`#2563eb` → hover `#1d4ed8`
